# K logo - developer kit

Generated by brand/tools/build_web.py from brand/tools/brand.py - do not edit by hand. After any change to the master, rebuild the whole kit with `python3 brand/tools/build.py all`
(`python3 brand/tools/build_web.py` alone rebuilds only this folder).

| Folder | What |
| --- | --- |
| `svg/` | Production SVGs: minimal markup, tight viewBox, `role="img"` + `<title>` |
| `react/` | `KLogo` React component (React 18+, no other dependency) |
| `web-component/` | `<k-logo>` custom element (no framework) |
| `tokens/` | Colours and geometry: DTCG JSON, CSS, SCSS, Tailwind, Android, iOS, Flutter |

## Brand rules (built into the files)

- Every corner of the K is sharp; only containers (disc, app tile) are curved. Never recolour,
  rotate, stretch, outline or rearrange the facets.
- Brand yellow (#F6C105) never stands alone on white (1.67:1); it only
  appears inside the mark.
- Clear space: 1 stem width on every side = `0.2321` x the mark height.
- Minimum height: 16 px for the colour mark, badge and `mono-solid` (8 mm in print);
  128 px for the gapped `mono` / `white` (20 mm in print). Their construction gap is
  0.8% of the mark height: below 128 px it is less than one pixel and renders as a grey smudge,
  so use the solid mark there (`k-logo-mono-solid.svg`, `k-logo-white-solid.svg`).
- Both switches are built into the components: below 120 px `tech` draws the simplified
  tech icon (`k-logo-tech-small.svg`); below 128 px `mono` draws `mono-solid` and `white` draws the
  solid white mark. `<k-logo>` switches at any size; `<KLogo>` switches when `size` is a number or
  `"48px"` (a CSS length is unknown while React renders), so give small tech icons and one-colour
  marks a pixel size. With the standalone files, pick the file by the same rule.
- No name or wordmark is defined yet: do not set text next to or inside the mark as if it were one.
  The files carry the neutral title "K Logo": when the product has a name, replace the K Logo title and the
  `name` / `short_name` in `icons/web/site.webmanifest` (in the kit root) with the product name.

Edge shift is the largest distance (in 1024-grid units) between an edge here and the same edge in
the brand document, measured by the build. `k-logo-mono*` paint with `currentColor`: inline them to
take the text colour (as an `<img>` they render black), or use them as a CSS `mask-image` over a
`background-color`. The files have no width/height: always set a height. Gradient ids are
namespaced per file (`k-tech-a` ...), so different files can be inlined on one page; for several
inline copies of the same shaded file (one of them hidden, say), use `<img>` or a component, which
keep every copy's ids apart.

```html
<img src="svg/k-logo.svg" alt="" height="48">   <!-- alt="": the product name is next to it; else name it -->
<span style="color: var(--k-logo-mono)"><!-- paste svg/k-logo-mono.svg inline (>= 128 px high) --></span>
<span style="color: var(--k-logo-mono)"><!-- smaller: paste svg/k-logo-mono-solid.svg --></span>
```

## React

Copy `react/` into the app (TypeScript or a TS-aware bundler; `.tsx` uses the `react-jsx` runtime).

```tsx
import { KLogo } from './react';

<KLogo />                                          // colour, 48 px high, decorative (aria-hidden)
<KLogo variant="dimensional" size={96} title="Home" />
<KLogo variant="tech" size={48} />                 // < 120 px: simplified tech icon
<KLogo variant="mono" size={160} className="logo" style={{ color: 'var(--k-logo-mono)' }} />
<KLogo variant="mono" size={32} />                 // < 128 px: the solid one-colour mark
```

Props: `variant` (color | mono | mono-solid | white | badge | dimensional | tech), `size` (height; number = px, string = CSS length;
width follows the aspect ratio), `title` (accessible name; without it the SVG is `aria-hidden`),
`className`, `style`. Exported constants: `TECH_SMALL_MAX` (119) and `MONO_GAPPED_MIN` (128), the two
size switches. Gradient ids come from `useId`, so any number of logos can share a page
(with several React roots on one page, give each root its own `identifierPrefix`, as for any `useId`).
The only hook is `useId`, so on React 19 it also renders as a Server Component.

## Web component

```html
<script type="module" src="web-component/k-logo.js"></script>
<k-logo variant="color" size="48" label="Home"></k-logo>
<k-logo variant="mono" size="3rem" style="color: var(--k-logo-mono)"></k-logo>
```

Attributes: `variant`, `size` (number = px, else a CSS length such as `3rem`; not a percentage, which
has no definite height to resolve against here), `label` (accessible name; without it the logo is decorative). `mono` / `mono-solid` take the element's `color`; `white` is always white.
`tech` switches to the simplified drawing below 120 px, `mono` and `white` to the solid mark below
128 px, by the laid-out height (so `3rem` above is drawn solid).
Shadow DOM; ids are unique per element; attributes can change at runtime.

## Tokens

```css
@import "tokens/tokens.css";      /* --k-red ... --k-night, hex with an OKLCH upgrade */
.hero { background: var(--k-surface); color: var(--k-text); }   /* light + dark aliases */
.logo { height: 48px; margin: calc(48px * var(--k-clear-space)); }   /* margin: border-box padding would shrink the logo */
```

- `tokens.json` - W3C Design Tokens (DTCG 2025.10): `brand.color.*` (OKLCH with hex fallback),
  `neutral.*`, `semantic.light|dark.*` (aliases), `geometry.*`.
- `tokens.css` - custom properties; `@supports (color: oklch(0 0 0))` swaps in the brand's OKLCH
  definitions (the hex values are their 8-bit rounding, so a browser may paint them up to 1/255 apart);
  `prefers-color-scheme: dark` switches the semantic aliases (pin with `data-theme="light|dark"` on `<html>`).
- `tokens.scss` - `@use "tokens/tokens" as k;` then `k.$k-red`; with `@use "sass:map";`,
  `map.get(k.$k-colors, "blue")`.
- `tailwind.preset.js` - v3: `presets: [require('./tokens/tailwind.preset.js')]`; v4: `@config "./tokens/tailwind.preset.js";`.
  Classes `bg-k-red`, `text-k-ink`, `bg-k-night` ...
- `android/colors.xml` - copy to `res/values/`; `@color/k_red`, `R.color.k_blue`.
- `ios/BrandColors.swift` - add to the target; `Color.kRed`, `.foregroundStyle(.kBlue)`, `UIColor.kInk`.
- `flutter/brand_colors.dart` - `import 'brand_colors.dart';` then `BrandColors.red`.
